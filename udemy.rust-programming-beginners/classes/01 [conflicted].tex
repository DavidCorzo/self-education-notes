\section{Introduction}
\begin{itemize}
    \item What is Rust?
        \begin{itemize}
            \item System level programming language
            \item Graudon Hoare's part-time side project in 2006 and remained so for over 3 years.
            \item Mozilla got involved in 2009 once the language was mature enough to run basic tests and demonstrate its core concepts.
            \item It is sponsored by Mozilla.
            \item The Rust team is composed of both mozilla and non-mozilla members.
        \end{itemize}
    
    \item Why Rust?
        \begin{itemize}
            \item More secure, no null pointers, fast.
        \end{itemize}
\end{itemize}
