\section{How does a project start and evolve? What a project's main stages?}
\begin{itemize}
    \item It has 5 phases:
        \begin{enumerate}
            \item Initiation: the foundation of a project, a justification of why it is neededed, this will include a suggested budget and time frame.
            \item Planning: create a plan in which the PM needs to estimate the work, risks, resources. Find out the activities, scheduling and timing, budget, project roles. All of the research done in this phase will be included in a document named project management plan. Planning = strategy for winning.
            \item Execution: the actual activities start, all the members of the team are assigned work.
            \item Monitoring and control: this does not start after execution but rather is done at the same time as the execution phase and answers the following question:
                \begin{itemize}
                    \item Progress done? how well are we doing with respect to the time frame? the budget used will be enough? any delays or gaps?
                \end{itemize}
            
            \item Closure phase: the final tasks, handing the project to the person who will use it, the person recieving it must sign off and confirm that it is complying with the terms. Them the PMs, stake holders and team sit down and share the lessons learned in the just finished project, feedback is collected and rest until the next project begins.
        \end{enumerate}
\end{itemize}
