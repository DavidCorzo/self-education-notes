\section{Introduction and installation}
\begin{itemize}
    \item Qt5 is a framework for making graphical user interfaces in C++.
    \item It is a powerful language, there are two licenses: commercial and free.
    \item Qt5 works with Visual Studio, so you need to install it.
    \item Install the C++ associations in Visual Studio.
    \item Go to: \url{https://www.qt.io/offline-installers}
    \item Download and install the version that suits your operating system.
\end{itemize}
